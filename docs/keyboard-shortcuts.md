# Keyboard shortcuts

This document lists all keyboard shortcuts in MonoSketch.

In this document, **Cmd** is the Command key on macOS. On Windows and Linux, use the Ctrl key.

## When the shortcuts work

The shortcuts work only when the page body has the keyboard focus. They do not work when you type in a text field, a modal or the text editor.

If a shortcut does not work, click an empty part of the board. Then try again.

## Tools

| Key | Tool |
|---|---|
| V | Select |
| R | Rectangle |
| T | Text |
| L | Line |

## Selection

| Key | Action |
|---|---|
| Cmd+A | Select all shapes. |
| Esc | Clear the selection. |
| Enter | Edit the text of the selected text shape. |

## Edit

| Key | Action |
|---|---|
| Delete or Backspace | Delete the selected shapes. |
| Arrow keys | Move the selected shapes by 1 cell. |
| Shift+Arrow keys | Move the selected shapes by 5 cells. |
| Cmd+C | Copy the selected shapes. |
| Cmd+X | Cut the selected shapes. |
| Cmd+V | Paste shapes or plain text. |
| Cmd+D | Duplicate the selected shapes. |
| Cmd+Shift+C | Copy the selected shapes as plain text. |
| Cmd+Z | Undo. |
| Cmd+Shift+Z | Redo. |

You can hold down the arrow keys, Cmd+Z and Cmd+Shift+Z. The action then repeats.

## Text editor

| Key | Action |
|---|---|
| Esc | Close the editor. |
| Cmd+Enter | Close the editor. |

The text editor saves the text when it closes.

## Mouse modifiers

| Modifier | When | Effect |
|---|---|---|
| Shift | Click a shape | Add the shape to the selection, or remove it. |
| Shift | Drag a selection rectangle | Add the shapes to the current selection. |
| Shift | Draw a line | Make a straight horizontal or vertical line. |
| Shift | Drag a line end | Keep the moved segments and add a new bend. |
| Shift | Scroll | Swap the vertical-only and horizontal-only scroll modes. |
| Alt (Option) | Scroll | Swap the horizontal and vertical scroll directions. |

## Hint panel

To show the hint panel, open the app menu and click **Keyboard shortcuts**.

The hint panel shows only some of the shortcuts. It does not show the arrow keys, copy, cut and paste.
